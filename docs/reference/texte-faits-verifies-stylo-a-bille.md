# Faits vérifiés : stylo à bille clic (épisode 2)
- Bille : diamètre généralement 0,7 à 1 mm (Wikipédia FR) ; plage totale 0,28 à 1,6 mm (Wikipédia EN). Matériaux : acier, laiton, carbure de tungstène ; le carbure de tungstène a remplacé l'inox en 1961 (Wikipédia FR).
- Douille : la bille est tenue dans une douille avec un arrêt mécanique qui l'empêche de tomber ou de sortir ; l'encre arrive par de petits canaux (Engineers Garage ; Wikipédia EN).
- Encre : pâte visqueuse dite « grasse », pigments/colorants + acides gras et solvants ; les acides gras lubrifient la bille et limitent son usure ; sèche presque immédiatement (Wikipédia FR/EN). Trop fluide : fuite ; trop épaisse : n'écrit pas (Engineers Garage).
- Réserve : tube plastique rempli d'encre, la gravité et la capillarité amènent l'encre vers la bille (Engineers Garage ; Wikipédia EN).
- Clic : came rotative qui tourne d'un petit angle à chaque poussée et se verrouille alternativement dans deux positions (pointe sortie / rentrée) ; ressort de rappel (brevet US9296250, description d'un mécanisme à came). Wikipédia EN : mécanisme rétractable « à ressort ou à vis ».
- Clip, corps : rôles courants (tenir en main, accrocher à une poche), pas de chiffre avancé.
- Non utilisé : trou du capuchon (concerne le Bic Cristal à capuchon, pas le stylo clic).
