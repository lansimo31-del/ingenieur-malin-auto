# Faits vérifiés : cailloux sous les rails (ballast)

| # | Fait retenu | Source |
|---|---|---|
| 1 | Chaleur : la résistance latérale du ballast est la défense principale de la voie contre le flambement par temps chaud ; le flambement survient quand la poussée dépasse cette résistance | Railway Track & Structures (rtands.com/?p=65304) |
| 2 | Le ballast résiste aux forces de l'acier qui « cherche à se dilater ou à se contracter » | CFF, livret « Mieux comprendre la voie ferrée » (news.sbb.ch) |
