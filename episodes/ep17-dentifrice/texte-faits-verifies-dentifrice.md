# Faits vérifiés : le carré de couleur du tube de dentifrice (épisode 17, pilier « Ce n'est pas un défaut, c'est fait exprès »)

Recherche du 9 nov. 2026 (soir). parismatch.be, maldita.es, snopes.com et colgate.com ne sont pas joignables depuis le cloud : sources lues par **résumé de moteur de recherche** (secondaires). Le script ne contient aucun chiffre ni aucune date.

| # | Fait retenu | Utilisé | Sources |
|---|---|---|---|
| 1 | Au bout du tube, un petit carré (ou rectangle) de couleur est imprimé : c'est une « marque d'œil » (eye mark) | oui | Paris Match Belgique ; Snopes ; Maldita ; Colgate |
| 2 | Un capteur optique (faisceau lumineux) lit la marque pour savoir où couper, plier et souder le tube | oui | Paris Match Belgique ; Snopes ; Colgate ; Municipalité de Dubaï (via Gulf News) |
| 3 | Les emballages défilent à grande vitesse dans les machines | oui (« très vite ») | Snopes (high-speed machinery) |
| 4 | La couleur doit contraster avec le fond du tube pour être détectée ; chaque fabricant choisit la sienne | oui | Paris Match Belgique ; Snopes ; sources concordantes du moteur |
| 5 | Il n'existe pas de code couleur (noir = chimique, vert = naturel…) : la rumeur est fausse | oui | Colgate (« le système de code couleur n'existe tout simplement pas ») ; Maldita ; Snopes ; Gulf News (Dubaï) |
| 6 | Les ingrédients sont écrits sur l'emballage (la boîte) | oui | Paris Match Belgique |

## Points divergents
- **Couleurs « possibles »** : le script cite noir, vert, bleu, rouge parce que ce sont celles de la rumeur (Maldita, Paris Match) ; la couleur réelle varie selon le fabricant et le tube.
- **Pourquoi telle couleur** : une source de moteur dit que le choix tient aussi à l'encre déjà chargée dans l'imprimeuse : non utilisé (non recoupé).
- **Marque visible ou non** : selon Snopes, la marque n'est pas toujours visible sur le produit fini ; le script dit seulement « tout au bout ».
- Le même système sert pour d'autres emballages (briques de lait selon Maldita) : non utilisé.
- Sujet très traité à l'écrit ; aucune vidéo avec ses likes lue (TikTok illisible depuis le cloud, captcha) : pas déclaré saturé faute de chiffre.
