## Points divergents
- Une source isolée donne 1928 pour le brevet de Rosati : non vérifiée, écartée au profit de 1930 (brevets cités par Cooks Info).
- Le prénom varie : Domenico, Domenick, Dominick. Le script dit « Dominick Rosati », comme les sources fondées sur le brevet.
- Le principe à double levier existe avant Rosati (brevet britannique de H. S. Heeley, 1888, d'un autre type) : le script dit « le premier brevet américain de ce modèle », pas « l'inventeur ».
- Le script dit « ce qui est bouché sort » pour ne pas nommer l'objet avant la chute.
- Aucune vidéo concurrente trouvée par la recherche le 13/11 ; TikTok illisible depuis le cloud.
