# Faits vérifiés : le petit trou sous le cadenas (épisode 11, `fait_expres`)

Recherche du 6 nov. 2026. Les pages monroeengineering.com et housedigest.com n'étaient pas joignables depuis le cloud : les faits reposent sur les résumés de la recherche web (blogs et pages grand public ; **aucune source de fabricant ou de normes**). À recouper dès que le réseau le permet.

| # | Fait | Utilisable dans le script | Sources |
|---|---|---|---|
| 1 | Le petit trou sous un cadenas sert à évacuer l'eau et l'humidité entrées dans le mécanisme | oui | keops-ingenierie.fr ; pulse.sn ; allpadlocks.com ; monroeengineering.com (résumés) |
| 2 | L'eau stagnante favorise la rouille des pièces en acier (ressorts, goupilles) et peut gripper le mécanisme | oui | allpadlocks.com ; keops-ingenierie.fr ; pratiquesinfos.com |
| 3 | L'eau qui gèle occupe plus de volume que l'eau liquide : la glace peut fissurer ou casser des pièces internes | oui | housedigest.com ; monroeengineering.com ; natureagreable.com (résumés) |
| 4 | Le trou sert aussi à glisser quelques gouttes de lubrifiant dans le mécanisme | oui | pour-mieux-apprendre.com ; comment-economiser.fr ; allpadlocks.com |
| 5 | Boucher le trou piège l'humidité et accélère la corrosion | oui (« ne le bouche jamais ») | keops-ingenierie.fr (titre : « pourquoi il ne faut pas le boucher ») ; natureagreable.com |
| 6 | Ce n'est pas une entrée pour ouvrir le cadenas sans clé (sauf rares modèles professionnels à trou de contournement) | oui, dans l'accroche (fausse piste) | pulse.sn ; comment-economiser.fr |
| 7 | Conseil d'orienter le trou vers le bas | non (une seule source) | pratiquesinfos.com |

## Points divergents
- Aucune source de fabricant ni étude technique : les explications du drainage, du gel et de la lubrification concordent entre elles, mais restent des sources grand public.
- Le « gel qui casse le mécanisme » est présenté comme un risque (« peut »), jamais comme une certitude : le script dit « peut fissurer ».
