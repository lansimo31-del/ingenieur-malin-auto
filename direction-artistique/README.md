# Direction artistique (épisodes 1 et 2)

Source de vérité : le code de `render/` (le style est reproduit à partir du code, car les vidéos
de référence ne sont que sur le Mac d'Ilan et sur Instagram).

| Élément | Valeur |
|---|---|
| Fond | Papier Seyès procédural (`paper_img` dans `render/pal/stylo.py`), marge `150,205,180` |
| Encre | Noire (`NOIR=1`), traits fixes, champ de déplacement statique, aucun tremblement |
| Accent | Vert `18,150,100` (`ACC`), réservé au mot-clé et aux éléments importants |
| Polices | Caveat gras ×1,32 (titres), Patrick Hand ×1,18 (petits textes) : `render/fonts/` |
| Format | 1080×1920, 30 ips, libx264 crf 17, supersampling ×2 |
| Son | Voix Enzo (Gemini TTS) au premier plan, musique synthétisée 104 bpm à gain 0,17, « pop » discrets, loudnorm I=-14, **aucun bruit de stylo** |
| Texte | Légendes karaoké synchronisées mot à mot, curseur qui pointe les éléments |
| Miniature | Voir `docs/sources/texte-regles-miniature-et-publication.md` (zone utile y 240 à 1680) |
